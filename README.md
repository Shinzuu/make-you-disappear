# Make you disappear

A design-course demonstration: an interactive landing page for a fictional night-relocation company, built for a UI/UX class homework (moodboard, AI-assisted build, interactive 3D background, responsive layout).

**This is not a real business and offers no real service.** All names, prices, testimonials and copy are fictional and exist only to demonstrate design, motion and prompting technique.

- Live page: https://make-you-disappear.vercel.app
- Backup copy (same files, Cloudflare Pages): https://make-you-disappear.pages.dev
- How it was made (prompts, moodboard references): https://make-you-disappear.vercel.app/process/

The 3D engine and fonts are served from this site (`vendor/`), with no third-party hosts. If the Vercel copy cannot load its critical files within 5 seconds, the page sends the viewer once to the backup copy.
